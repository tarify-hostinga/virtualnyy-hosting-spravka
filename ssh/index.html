Вопросы и ответы

Даёт ли Beget доступ по SSH на виртуальном хостинге?

Да, консоль доступна и на хостинге, не только на серверах. Учётные данные те же, что для панели управления.

Какой логин и пароль использовать для SSH?

Логин и пароль аккаунта Beget. Отдельный доступ создавать не нужно, адрес сервера показан в панели.

Можно ли подключиться по SSH из Windows?

Да, встроенным клиентом в терминале или через PuTTY. В базе знаний провайдера есть инструкции для обоих вариантов.

Почему после переноса аккаунта SSH ругается на отпечаток?

Аккаунт оказался на другой машине, и её отпечаток не совпадает с сохранённым. Старую запись удаляют из файла известных хостов.
