Коротко

Node.js на Beget запускают по-разному в зависимости от того, что делает приложение: если оно постоянно слушает порт, как API, бот или сайт на серверном рендеринге, ему нужен VPS с менеджером процессов. Если Node только собирает фронтенд, а наружу отдаётся готовая статика, хватает обычного хостинга. Постоянному Node-приложению нужен VPS с менеджером процессов, а не хостинг сайтов.

Вопросы и ответы

Можно ли запустить Node.js на хостинге Beget?

Только для сборки статики: если Node собирает фронтенд, а отдаётся готовый HTML. Постоянному приложению нужен VPS.

Почему Node-приложению нужен VPS?

Потому что оно постоянно слушает порт, в отличие от PHP-сайта, который обрабатывает запрос и завершается. Для постоянного процесса нужен root-доступ.

Как держать Node-приложение запущенным?

Через менеджер процессов с автозапуском: он поднимает приложение после сбоя и перезагрузки машины. Настраивается на VPS через консоль.

Нужен ли VPS для сайта на React?

Если наружу отдаётся собранная статика, нет: Node нужен только для сборки. VPS нужен при серверном рендеринге, когда Node работает в проде.
